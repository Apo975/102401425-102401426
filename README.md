# 校园失物招领小程序（第二次结对作业）

WEB 版，三件套，无后端，数据存浏览器 localStorage。

## 目录说明

```
practice4/
├── index.html   页面结构：首页 / 发布 / 搜索 / 详情 / 成功页
├── style.css    样式：布局、卡片、按钮
├── app.js       逻辑：发布 / 列表 / 搜索 / 详情 / 状态更新
└── README.md    本文件
```

## 使用说明

1. 用谷歌浏览器打开 `index.html`（双击即可，无需服务器）。
2. 首页浏览信息；点发布寻物 / 招领填写后发布。
3. 搜索页输入物品名称关键词搜索，点击卡片进入详情。
4. 详情页可查看联系方式，发布者可标记已找到 / 已归还。
